# NinXT

Fun with ESP.

### Prerequisites

* [ESP-IDF](https://docs.espressif.com/projects/esp-idf/en/stable/esp32/get-started/index.html)
* Set `IDF_PATH` environment variable

### Building

Call `bootstrap.sh` before building and after plugging in your dev board to USB.

Call `flash.sh` to flash and monitor.

Call `build.sh` to build only (no board required).
